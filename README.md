## 🎯 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 분석 질문 | 초과근무, 소득, 직급 같은 근무 조건 중 무엇이 이직과 가장 밀접하게 연관되어 있는가? |
| 데이터 | [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) (Kaggle, 1,470명 × 35열) |
| 참고 교재 | 『파이썬 라이브러리를 활용한 데이터 분석』 |
| 도구 | Python, pandas, matplotlib, Jupyter Notebook |

이직은 채용과 교육 비용 손실로 이어지기 때문에, 이직 위험이 높은 집단을 미리 알면 인사 관리에서 먼저 살펴볼 대상을 정할 수 있습니다.

---

## 💡 핵심 결과

| # | 발견 | 근거 |
| --- | --- | --- |
| 1 | 초과근무를 하는 직원의 이직률이 약 3배 높고, 모든 직급에서 같은 방향 | 초과근무 30.5% (416명 중 127명) vs 미초과 10.4% (1,054명 중 110명) |
| 2 | 월 소득 하위 25% 구간의 이직률이 두드러지게 높음 | 하위 25% 29.3%, 나머지 구간 10.3~14.2% |
| 3 | 소득과 이직의 관계에는 직급 효과가 크게 섞여 있음 | 직급 1의 이직률 26.3%, 직급 1이면서 초과근무하는 집단은 52.6% |

> **이 데이터에서 이직과 가장 뚜렷하게 연관된 조건은 초과근무와 초급 직급입니다.** 소득이 낮을수록 이직이 많아 보이는 현상은 상당 부분 초급 직급의 영향으로 보입니다.
